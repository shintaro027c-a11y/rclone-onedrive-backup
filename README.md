# rclone-onedrive-backup

## 概要
このアプリは、個人利用のためのクラウドバックアップツールです。

rcloneを使用して、Microsoft OneDriveのファイルを利用者本人のGoogle Driveへ一方向にコピーします。

## 主な機能
- OneDriveのファイルの読み取り
- Google Driveへのバックアップファイルの作成と更新
- Windowsパソコンでの定期的なバックアップ

## データの取扱い
ファイル転送は利用者本人のパソコン上で実行します。
認証情報は利用者のパソコンで管理し、公開リポジトリには保存しません。
このWebページ自体は、クラウド内のファイルを収集しません。
